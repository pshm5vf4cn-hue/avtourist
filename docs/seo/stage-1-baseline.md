## Ограничения
Позиции, показы, CTR, поисковые запросы, лиды и выручка по каналам пока неизвестны. Их нельзя использовать для выводов. Следующий аналитический этап — выгрузка Search Console и CRM.

## Следующие этапы
1. Подключить Search Console и выгрузить запросы, показы, CTR и страницы входа; после этого улучшать title и description по фактическим данным.
2. Получить у компании подтверждённые дела: исходную ситуацию, документы, действия юриста и результат. Публиковать кейсы без выдуманных сумм и обещаний.
3. Через 2–4 недели сравнить переходы, заявки и звонки с исходными показателями, учитывая малый объём текущего трафика.
4. Отдельно проверить скорость загрузки: PageSpeed API при первом аудите вернул ограничение квоты HTTP 429.
