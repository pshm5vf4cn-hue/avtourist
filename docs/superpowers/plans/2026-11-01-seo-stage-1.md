# SEO Stage 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Усилить коммерческие страницы и внутреннюю связность сайта без выдуманного контента.

**Architecture:** Локальные правки существующих HTML-страниц в текущем стиле. Статические проверки метаданных и ссылок, затем браузерная проверка и публикация через git.

**Tech Stack:** HTML, CSS, vanilla JS, Node.js для проверок, встроенный браузер.

**Spec:** `docs/superpowers/specs/2026-11-01-seo-stage-1-design.md`

## Global Constraints
Только подтверждённые факты компании. Не менять другие страницы и operator. Не добавлять зависимости или шаблонные SEO-страницы.

## Review Focus
- Отсутствие выдуманных кейсов, биографий и результатов.
- Отсутствие новых битых ссылок и дублей title/description.
- Корректная работа форм и Метрики после правок.
